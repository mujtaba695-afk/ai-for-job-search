# Resume Reframer — Honest Experience Repositioning

## ⚠️ THE RULE (Non-Negotiable)

**NEVER add, fabricate, inflate, or invent anything the user hasn't done.**

What this skill DOES:
- ✅ Reframes existing experience using the target role's language
- ✅ Shifts emphasis to the most relevant parts of existing experience
- ✅ Shows transferable skills the user genuinely has
- ✅ Restructures bullets to highlight what matters for the target role
- ✅ Uses the target JD's vocabulary to describe real experience
- ✅ Quantifies existing achievements more prominently
- ✅ Connects dots between past work and future responsibilities

What this skill NEVER does:
- ❌ Adds skills the user doesn't have
- ❌ Claims tools/platforms the user hasn't used
- ❌ Inflates metrics or results
- ❌ Adds job responsibilities the user didn't have
- ❌ Fabricates campaigns, projects, or outcomes
- ❌ Adds certifications the user hasn't earned
- ❌ Makes the user sound like someone they're not

## Workflow

### 1. Collect Inputs
- **Current resume** (file, text, or verbal description)
- **Target job description** (URL or text)

### 2. Extract User's ACTUAL Experience

Before touching the resume, map what the user ACTUALLY has:

```
## 📋 Your Actual Experience (What You Really Have)

### Channels You've ACTUALLY Worked With
- [List only channels the user confirms they've used]

### Tools You've ACTUALLY Used
- [List only tools the user confirms]

### Metrics You've ACTUALLY Achieved
- [List only real numbers the user provides]

### Responsibilities You've ACTUALLY Had
- [List only real duties]

### Industries You've ACTUALLY Worked In
- [List only real industries]

### Budgets You've ACTUALLY Managed
- [Only what user confirms]
```

**STOP. Ask the user to confirm this list before proceeding.**

### 3. Strength Mapping (The Core Process)

For each requirement in the JD, find the CLOSEST match in the user's existing experience:

```
## 🔗 Strength Mapping: Your Experience → JD Requirements

### JD Requirement: "Manage paid social campaigns across Meta and TikTok"
**Your Experience**: Managed Facebook advertising for e-commerce brand
**Reframe**: "Managed Facebook advertising campaigns for e-commerce brand,
driving [real metric]" → This IS paid social experience, just name it as such

### JD Requirement: "Optimize ROAS across channels"
**Your Experience**: Improved conversion rates on email campaigns
**Reframe**: Can't claim paid ROAS experience, BUT can say "Optimized
email conversion funnel, improving click-to-purchase rate by [X%]"
→ Shows optimization mindset without claiming paid channel experience

### JD Requirement: "Experience with Google Ads"
**Your Experience**: Never used Google Ads
**Honest Approach**: Don't add it. Instead, emphasize depth in platforms
you DO know. "Deep expertise in Meta Ads platform" or note it as a
growth area if asked in interview.

### JD Requirement: "Data-driven decision making"
**Your Experience**: Used analytics to report on campaign performance
**Reframe**: "Leveraged data analytics to inform campaign decisions
and report on performance metrics" → Same work, better framing
```

### 4. Reframing Techniques

#### Technique 1: Language Alignment
Use the JD's exact words to describe your real experience:

| Your Original | JD Language | Reframed (Honest) |
|---|---|---|
| "Ran Facebook ads" | "Paid social campaign management" | "Managed paid social campaigns on Facebook" |
| "Made reports" | "Performance analytics and reporting" | "Built performance analytics reports tracking [metrics]" |
| "Tested different ads" | "A/B testing and creative optimization" | "Conducted A/B tests to optimize ad creative performance" |
| "Worked with budget" | "Budget allocation and management" | "Managed advertising budget of [amount] with focus on [goal]" |
| "Posted on social media" | "Social media content strategy" | "Developed and executed social media content strategy" |

#### Technique 2: Emphasis Shift
Same experience, different angle:

**For a data-focused role:**
> "Analyzed campaign performance data across 3 channels, identifying
> optimization opportunities that improved efficiency by 15%"

**For a creative-focused role:**
> "Developed and tested 20+ ad creative variations, identifying
> top-performing formats that drove 15% efficiency improvement"

Both are TRUE — just different emphasis.

#### Technique 3: Transferable Skill Extraction
Show how existing skills APPLY to the new role:

| Your Experience | Transferable Skill | How It Applies |
|---|---|---|
| Managed a team of 3 | Team leadership | "Led cross-functional team, skills transferable to managing marketing specialists" |
| Client presentations | Stakeholder management | "Presented results to senior stakeholders, managing expectations and communicating ROI" |
| Project management | Campaign operations | "Managed multiple concurrent projects with deadlines, budgets, and cross-team coordination" |
| Sales experience | Revenue focus | "Revenue-driven mindset with direct experience in conversion funnels and customer acquisition" |

#### Technique 4: Scope Honestification
Scale doesn't need to be inflated — frame it properly:

| Small Scale | Honest Frame |
|---|---|
| Managed $2K/month budget | "Managed advertising budget, optimizing for efficiency at every dollar" |
| Solo contributor | "Independently managed end-to-end campaign operations" |
| One client/account | "Owned full-funnel performance for [brand/account]" |
| Intern/Junior | "Contributed to campaign execution and learned [specific skills]" |

### 5. Output

```
## 📝 Reframed Resume

### Changes Made (Transparent)

#### [Job Title] — [Company]

**Original**: Ran Facebook ads for the company store
**Reframed**: Managed paid social advertising campaigns on Facebook,
driving [real metric if available]

**Why**: "Ran" undersells the work. "Managed paid social advertising
campaigns" uses industry-standard language for the same work.

---

**Original**: Created monthly reports for management
**Reframed**: Developed monthly performance analytics reports tracking
KPIs including [real metrics], informing budget and strategy decisions

**Why**: Shows the PURPOSE of the reports, not just the task.

---

**Original**: Helped with marketing projects
**Reframed**: Supported cross-functional marketing initiatives including
[real specific projects]

**Why**: "Helped with" is vague. "Supported cross-functional initiatives"
is specific and professional.

### NOT Changed (Honest)
- Did NOT add Google Ads experience (user hasn't used it)
- Did NOT inflate budget from $2K to $50K
- Did NOT add team management if user was solo
- Did NOT claim ROAS metrics if user doesn't have them
```

### 6. Gap Strategy

For skills the user genuinely DOESN'T have:

```
## 🚧 Gaps You Should Address Honestly

### In the Resume
- Don't mention skills you don't have
- Emphasize depth in skills you DO have
- Show learning agility: "Quick to adopt new platforms and tools"

### In the Cover Letter
- Acknowledge gaps proactively: "While my direct experience with
  [tool] is developing, my proven ability to [related skill]
  positions me to ramp up quickly"

### In the Interview
- "I haven't used [tool] specifically, but I've used [similar tool]
  and I'm confident I can pick it up quickly. I'm actually already
  [taking a course / watching tutorials / practicing] on it."
```

## Anti-Fabrication Checklist

Before finalizing, verify EVERY bullet:

```
□ Every tool mentioned — user has ACTUALLY used it
□ Every metric — user has ACTUALLY achieved it
□ Every responsibility — user has ACTUALLY held it
□ Every campaign — user has ACTUALLY worked on it
□ Every certification — user has ACTUALLY earned it
□ Every team size — user has ACTUALLY managed that many
□ Every budget — user has ACTUALLY managed that amount
□ Every industry — user has ACTUALLY worked in it

If ANY answer is "no" → REMOVE it or reframe honestly
```

## Rules

1. **Honesty is non-negotiable** — never fabricate, period
2. **Reframing is not lying** — using better words for real work is professional
3. **When in doubt, leave it out** — better to understate than overclaim
4. **Ask the user to confirm** — verify experience before reframing
5. **Show the changes transparently** — explain what changed and why
6. **Gaps are okay** — everyone has them, address them honestly
7. **Depth > breadth** — deep expertise in 2 platforms beats shallow claims of 10
