# Personal Brand Auditor — Marketing Professional

## Audit Checklist

### 1. Google Search Audit
```
Search: "[Your Name]" + "marketing"
Search: "[Your Name]" + "[Company]"

Results:
- [ ] First page results are professional
- [ ] LinkedIn profile appears top 3
- [ ] No embarrassing social media posts
- [ ] Portfolio/website appears if exists
- [ ] No negative press or reviews
```

### 2. LinkedIn Audit
```
- [ ] Professional headshot (not selfie, not group photo)
- [ ] Headline includes target keywords (not just job title)
- [ ] Summary is keyword-rich and compelling
- [ ] Experience has quantified achievements
- [ ] Skills section has 50+ endorsements for top skills
- [ ] Recommendations from managers/clients (minimum 3)
- [ ] Featured section has portfolio pieces
- [ ] Activity shows regular engagement (not dormant)
- [ ] No typos or inconsistencies
```

### 3. Content Presence
```
- [ ] Regular LinkedIn posts about marketing topics
- [ ] Comments on industry leaders' posts
- [ ] Articles or posts demonstrating expertise
- [ ] Sharing industry news with thoughtful commentary
- [ ] Engagement with target companies' content
```

### 4. Portfolio/Site
```
- [ ] Personal website exists (optional but powerful)
- [ ] Case studies with real metrics
- [ ] Contact information visible
- [ ] Mobile-friendly
- [ ] Fast loading
- [ ] Professional domain name
```

### 5. Consistency Check
```
- [ ] Same name across all platforms
- [ ] Same professional photo
- [ ] Consistent story/title across LinkedIn, site, resume
- [ ] No conflicting information
```

## Rules
- Actually search for the user's name online (use mimo_web_search)
- Be honest about what recruiters will find
- Focus on marketing-specific brand signals
- Prioritize LinkedIn above all other platforms for this audience
