## Goals & Targets

### Application Volume
- **Aggressive**: 15-20 applications/week
- **Moderate**: 8-12 applications/week
- **Quality-focused**: 5-8 highly tailored applications/week

### Response Rate Benchmarks
| Rate | Assessment |
|---|---|
| <10% | Resume/keywords need work → Use resume-tailor |
| 10-20% | Normal range → Keep going |
| 20-30% | Strong → Focus on interview prep |
| >30% | Excellent → You're targeting right |

## Pattern Analysis

After 2-3 weeks, analyze:
- Which job boards have best response rates?
- Which resume version gets more callbacks?
- What time of day gets fastest responses?
- Which companies respond vs. ghost?

## Rules
- Run check-ins weekly (or as scheduled)
- Be honest about effort levels
- Celebrate small wins (every interview is progress)
- Adjust strategy based on data, not feelings
- If stuck for 2+ weeks, change something (resume, targets, approach)
