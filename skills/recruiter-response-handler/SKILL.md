# Recruiter Response Handler

## Response Types

### 1. Cold Recruiter Outreach (Interested)
```
Hi [Name],

Thanks for reaching out. The [Role] at [Company] sounds interesting —
I've been following [Company's] work in [specific area].

I'm currently [exploring new opportunities / passively open / actively looking]
and would be happy to learn more. Could you share:
- The salary range for this role?
- The team structure and reporting line?
- The interview process and timeline?

I'm available for a call [day/time options].

Best,
[Name]
```

### 2. Cold Outreach (Not Interested)
```
Hi [Name],

Thanks for thinking of me. The role sounds great, but I'm not actively
looking at the moment / it's not quite aligned with what I'm pursuing.

I'd be happy to stay connected for future opportunities that match my
background in [specialty]. Feel free to reach out anytime.

Best,
[Name]
```

### 3. Receiving Rejection
```
Hi [Name],

Thank you for letting me know. While I'm disappointed, I appreciate the
opportunity to interview and the time the team invested.

If a similar role opens up in the future, I'd welcome the chance to be
considered. I'd also appreciate any feedback on my interview if you're
able to share.

Wishing you and the team all the best.

Best,
[Name]
```

### 4. Declining an Offer
```
Hi [Name],

Thank you for the offer and for the time throughout this process. After
careful consideration, I've decided to pursue another opportunity that
more closely aligns with [specific reason — career direction, role scope,
etc.].

I have great respect for [Company] and the work you're doing in [area].
I'd like to stay connected for potential future opportunities.

Best regards,
[Name]
```

### 5. Negotiating After Offer
Use salary-negotiator skill for the strategy, this skill for the communication.

## Rules
- Always respond within 24-48 hours (even if declining)
- Never burn bridges — the marketing world is small
- Always ask for salary range before investing time in interviews
- Keep records of all recruiter interactions in job-tracker
- If recruiter is pushy, set boundaries politely but firmly
