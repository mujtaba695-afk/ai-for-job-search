# LinkedIn Optimizer — Performance & Digital Marketing

## Workflow

### 1. Collect Inputs

- **Current LinkedIn profile** (URL, pasted text, or description)
- **Target role** (specific job title or general direction)
- **Target market** (country/region for keyword localization)

### 2. Profile Audit

Analyze each section against target role:

| Section | Check |
|---|---|
| **Headline** | Contains target keywords? Shows value prop? Not just job title? |
| **About** | Keyword-rich? Tells a story? Quantifies impact? CTA? |
| **Experience** | Mirrors target JD language? Quantified achievements? |
| **Skills** | Top 3 match must-have skills? Endorsed? |
| **Featured** | Case studies, results, portfolio pieces? |
| **Recommendations** | Relevant people? Performance-focused? |

### 3. Rewrite Each Section

#### Headline Formula (220 chars max)
```
[Target Role] | [Specialty] | [Key Platforms] | [Result Type]
```
Example: `Performance Marketing Manager | Paid Social & Search | Google Ads, Meta, TikTok | Driving 4x+ ROAS at Scale`

#### About Section (2,600 chars max)
```
[Hook — what drives you professionally]

[2-3 sentences on core expertise — mirror JD keywords]

[Quantified achievements — 3-4 bullet points with numbers]

[Tools/platforms paragraph]

[CTA — what you're looking for / how to reach you]
```

#### Experience Bullets
- Start with power verbs matching target JD
- Include metrics: budget, ROAS, CPA, revenue, team size, channels
- Mirror exact terminology from target roles
- 3-5 bullets per role, most recent roles get more

### 4. SEO & Keyword Optimization

- Research top keywords recruiters search for marketing roles
- Ensure keywords appear in: Headline, About, Experience titles, Skills
- Use both full forms and abbreviations: "Search Engine Marketing (SEM)"
- Location keywords for geo-targeted search

### 5. Output

Provide a complete rewritten profile ready to copy-paste into LinkedIn, with change notes explaining each modification.

## Key Rules

- **Keyword density matters** — LinkedIn search is keyword-based
- **Quantify everything** — Numbers catch recruiter eyes
- **No buzzwords without proof** — "Results-driven" needs results
- **Mobile-first** — Most recruiters browse on mobile, keep paragraphs short
