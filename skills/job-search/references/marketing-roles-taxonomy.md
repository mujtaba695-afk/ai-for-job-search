# Performance & Digital Marketing — Role Taxonomy

## Role Title Patterns

Use these to identify relevant roles in search results:

### Core Titles
- Performance Marketing Manager / Specialist / Director
- Paid Media Manager / Specialist / Director
- Growth Marketing Manager / Lead / Director / VP
- PPC Manager / Specialist / Analyst
- SEM Manager / Specialist / Analyst
- Paid Search Manager
- Paid Social Media Manager / Specialist
- Digital Marketing Manager (with paid focus)
- Programmatic Media Buyer / Planner / Specialist
- Display Advertising Manager
- Video Advertising Specialist

### Platform-Specific Titles
- Google Ads Specialist / Manager
- Meta (Facebook) Ads Manager / Specialist
- TikTok Ads Manager / Specialist
- LinkedIn Ads Specialist
- Amazon Advertising Specialist / Manager
- Apple Search Ads Manager
- Snapchat Ads Manager
- Twitter/X Ads Specialist

### Adjacent (Acceptable)
- Marketing Analyst (paid channel focus)
- Conversion Rate Optimization (CRO) Manager
- Affiliate Marketing Manager
- E-commerce Marketing Manager
- DTC Marketing Manager
- App Growth / UA Manager
- Marketing Operations Manager (with paid focus)
- Demand Generation Manager
- Revenue Marketing Manager

### Exclude (Not Relevant)
- Content Marketing Manager (unless paid distribution focus)
- Social Media Manager (organic only)
- SEO Manager / Specialist
- Brand Manager (unless paid brand campaigns)
- PR / Communications
- Marketing Coordinator (generalist)
- Graphic Designer
- Marketing Intern (unless user requests)
