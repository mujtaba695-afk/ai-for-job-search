# Skills Gap Analyzer — Performance & Digital Marketing

## Workflow

### 1. Assess Current State

Collect from user (or extract from resume):
- Years of experience
- Platforms/tools used
- Channels managed
- Budget scale handled
- Certifications held
- Industries worked in

### 2. Define Target State

Either from a specific JD or a general target role:
- Required skills
- Required experience level
- Required certifications
- Preferred qualifications

### 3. Gap Analysis

```
## 📊 Skills Gap Analysis

### Current Profile
- Experience: [X years in Y]
- Platforms: [list]
- Channels: [list]
- Budget: [range]
- Certifications: [list]

### Target: [Role] at [Company/Industry]

### Gap Report

| Skill | Current Level | Required | Gap | Priority |
|---|---|---|---|---|
| Google Ads | ⭐⭐⭐⭐ Advanced | ⭐⭐⭐⭐ Advanced | ✅ None | — |
| Meta Ads | ⭐⭐⭐ Intermediate | ⭐⭐⭐⭐ Advanced | ⚠️ Medium | 🔴 High |
| TikTok Ads | ⭐ None | ⭐⭐⭐ Intermediate | ❌ Major | 🔴 High |
| GA4 | ⭐⭐ Basic | ⭐⭐⭐ Intermediate | ⚠️ Medium | 🟡 Medium |
| Data Studio | ⭐ None | ⭐⭐ Basic | ⚠️ Medium | 🟡 Medium |
| Budget Management | $50K/mo | $200K/mo | ⚠️ Scale gap | 🟢 Low |

### Match Score: 65%
```

### 4. Learning Plan

Prioritized action plan with timelines and resources:

```
## 📚 Learning Plan — 90 Days

### 🔴 Priority 1: TikTok Ads (Weeks 1-4)
- Complete TikTok Academy certification (free)
- Set up practice account, run $500 test campaign
- Study: TikTok Ads Manager documentation
- Goal: Reach intermediate level

### 🔴 Priority 2: Advanced Meta Ads (Weeks 1-6)
- Complete Meta Blueprint advanced courses
- Practice: Advantage+ campaigns, broad targeting
- Study: Meta's performance marketing playbook
- Goal: Build 2 case studies with ROAS > 4x

### 🟡 Priority 3: GA4 & Looker Studio (Weeks 4-8)
- Google Analytics certification (free)
- Build 3 dashboards in Looker Studio
- Goal: Can build performance reports independently

### 🟢 Priority 4: Budget Scale (Ongoing)
- Volunteer for higher-budget campaigns at current job
- Take on freelance clients with larger budgets
- Document everything for portfolio
```

### 5. Resources

Provide specific, actionable resources:
- Free certifications: Google Skillshop, Meta Blueprint, TikTok Academy, HubSpot
- Paid courses: CXL, Coursera, Udemy (specific course recommendations)
- Practice: personal projects, pro-bono work, freelance platforms
- Communities: for peer learning and mentorship

## Rules

- **Be honest** — don't sugarcoat gaps
- **Be specific** — "learn more about TikTok" is useless; "complete TikTok Academy certification" is actionable
- **Prioritize** — not all gaps are equal; focus on high-impact, quick-win skills first
- **Create a timeline** — vague "someday" plans don't work
- **Celebrate strengths** — acknowledge what they're already good at
