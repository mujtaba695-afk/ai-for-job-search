# Competitor Candidate Analysis

## Analysis Framework

### 1. Typical Competitor Profile

For any given role, estimate the competition:

```
## 🎯 Competition Analysis: [Role] at [Company]

### Typical Competitor Profile
- Experience: [X-Y years]
- Background: [Agency / In-house / Mix]
- Platforms: [Common platform experience]
- Education: [Typical degree/certifications]
- Salary expectation: [Range]

### Likely Competitor Count
- LinkedIn applicants: [X] (check LinkedIn job posting)
- Total applicants: [Estimated X-Y]
- Qualified candidates: [Estimated X-Y]
- Final round candidates: [3-5]

### Competitive Landscape
| Factor | Average Competitor | You | Advantage? |
|---|---|---|---|
| Years of Experience | 4-5 years | [yours] | |
| Platform Breadth | 3-4 platforms | [yours] | |
| Budget Managed | $50-100K/mo | [yours] | |
| Certifications | 2-3 | [yours] | |
| Industry Experience | [common industry] | [yours] | |
| Team Management | 0-2 people | [yours] | |
```

### 2. Differentiation Strategy

```
## 💡 How to Stand Out

### Your Unique Advantages
1. [What you have that most competitors don't]
2. [Unique combination of skills]
3. [Specific result that's uncommon]

### Gaps to Address Proactively
1. [What you're missing — address in cover letter/interview]
2. [How to frame it positively]

### Application Differentiators
- Resume: [What makes yours different]
- Cover letter: [Unique hook]
- Portfolio: [What to showcase]
- Interview: [Stories that set you apart]
```

### 3. LinkedIn Applicant Insights

If the job is on LinkedIn, check:
- Number of applicants
- Seniority distribution of applicants
- Common backgrounds among applicants

## Rules
- Don't discourage — competition is normal
- Focus on differentiation, not comparison
- Help user find their unique angle
- Every candidate has weaknesses — help user exploit competitor gaps
